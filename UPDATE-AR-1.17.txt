تحديث RAM 1.17 — تقرير العمل ونقاش الصفقة دون شاشة سوداء

ارفع app/src/main/assets/app.js إلى المسار نفسه في مستودع RAM-Agent، مع استبدال الملف، ثم ارفع هذا الملف التوضيحي إلى جذر المستودع. ارفع التغييرات إلى main وانتظر GitHub Actions لبناء APK.

بعد اختيار فرصة، يفتح رام «الأعمال الجارية» ويعرض أسفل الصفقة تقريرًا تفصيليًا عن المطلوب والمتطلبات والخطة، مع مربع نقاش خاص بها لتوجيه رام وطلب التوضيح أو التعديل. مسودة المخرج تظهر في بطاقة العمل نفسها. عند انقطاع الاتصال تظهر رسالة داخل العمل ولا تسجل المهمة كمنجزة.

الاختبارات: فحص JavaScript واختبارات المشروع الـ17 نجحت. هذا تحديث مصدر؛ يجب إعادة بناء APK عبر GitHub Actions قبل استخدامه.

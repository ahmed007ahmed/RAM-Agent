RAM 1.24 — إصلاح اختبارات Cloudflare/n8n والبحث وإضافة كتالوج الأدوات

1) فك ضغط RAM-1.24-PATCH.zip في جذر مستودع RAM-Agent، مع الحفاظ على المسارات واستبدال الملفات الموجودة.
2) ارفع الملفات إلى main في GitHub. لا ترفع أسرار Cloudflare أو Gmail أو n8n أو كلمات المرور.
3) انتظر GitHub Actions: Build Signed APK v1.24. عند النجاح نزّل RAM-BUSINESS-SIGNED-APK-v1.24 وثبته بالتوقيع الدائم نفسه.
4) بعد اكتمال نشر Railway، افتح التطبيق وتحقق من الإعدادات والربط.
5) اضغط «اختبار محادثة Cloudflare AI» ثم اختبر البحث الحقيقي.
6) قبل «اختبار ربط n8n»، تأكد أن workflow يتجاهل الحدث test:true؛ الاختبار يرسل حدثًا إلى Webhook وقد يبدأ workflow غير المهيأ للفصل.
7) افتح كتالوج البرامج والمكونات الإضافية.
استخدم البحث والتصنيفات، زر «فتح الموقع الرسمي» للتسجيل بنفسك، «أضف لقائمتي» لحفظ الاختيار، و«لدي حساب» لتسجيل ملاحظة محلية.

لا يوجد OpenAI أو OpenRouter في المحادثة؛ المزود الوحيد هو Cloudflare AI. تفتح المواقع في المتصفح الخارجي. الاشتراك أو حفظ الحساب لا يكفي ليستخدم رام أي أداة: يلزم موصل OAuth/API واختبار مستقل لكل خدمة. حالة المفاتيح لا تعني أن الخدمة نجحت؛ استخدم اختبارات Cloudflare والبحث وn8n. اختبار n8n يرسل حدثًا معلّمًا test:true وقد يشغّل خطوات workflow إن لم تفصله.

افحص الأسعار، التجديد، والأهلية في بلدك قبل التسجيل. لا تدخل كلمات المرور أو مفاتيح API أو الدفع في رام. رام لا يدفع ولا يشترك ولا يجدد ولا يتداول.

التحقق المحلي: الاختبارات وnode --check وgit diff --check تُجرى على المصدر. لا تعني نجاح Cloudflare أو n8n الحي؛ يلزم الاختبار من التطبيق بعد نشر خادم Railway.

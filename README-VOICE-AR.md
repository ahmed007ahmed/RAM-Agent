# RAM voice session repair v1

هذا التحديث يحافظ على تكامل n8n الموجود ويغيّر التقاط الصوت فقط. يستبدل التعرف بجملة واحدة من Android بالتقاط WAV محلي من الميكروفون حتى يتوقف الكلام، ثم يحوّل المقطع كاملًا عبر Cloudflare Workers AI Whisper.

## الملفات
استبدل المسارات التالية في مستودع GitHub:
- `app/src/main/java/com/ram/agent/VoiceConversationService.java`
- `app/src/main/java/com/ram/agent/MainActivity.java`
- `app/src/main/assets/app.js`
- `server/server.js`

لا تستبدل ملفات `AndroidManifest.xml` أو `package.json`؛ إذن الميكروفون ومكتبات الخادم الحالية كافيان. يتضمن ملف الخادم تكامل n8n الحالي.

## خطوات النشر
1. انتظر اكتمال بناءي GitHub Actions رقم 164 و165 الظاهرين في صورتك. ثبّت APK الحالي فقط إذا نجحا.
2. بعد ذلك انسخ ملفات الحزمة الأربعة إلى المسارات نفسها وارفعها إلى GitHub.
3. انتظر نجاح GitHub Actions الجديد، ثم ثبّت APK الجديد. خادم Railway يعاد نشره من commit إذا كان الربط التلقائي مفعّلًا.
4. في إعدادات رام، راجع عنوان HTTPS للخادم. يجب نسخه كما يظهر في Railway > خدمة RAM-Agent > Settings > Networking > Public Domain. إذا كان العنوان الحالي يعطي UnknownHost، اضغط Generate Domain في Railway أو استخدم العنوان العام الحالي ثم احفظه في إعدادات رام.

## ما الذي يتطلبه Whisper؟
يستخدم المسار الجديد متغيري Railway الموجودين: `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN`. لا نحتاج مفتاحًا جديدًا. بعد البناء اختبر المحادثة؛ إذا ظهر رفض Workers AI، فالرسالة الآن تميّز فشل الصلاحية أو الاستخدام بدل الرسالة العامة.

يستمع رام على الهاتف، وينهي المقطع بعد نحو 1.3 ثانية من الصمت، ثم يرسله كاملًا (حتى 90 ثانية) للتفريغ النصي، وبعد رد رام يبدأ الاستماع من جديد. لا تستخدم هذه المرحلة خدمة البوق القديمة. هذا تبادل صوتي متتابع، وليس بثًا صوتيًا كاملًا أثناء الكلام؛ Whisper في Workers AI يعمل على المقاطع الصوتية. للصوت الطبيعي اختَر ElevenLabs في إعدادات الصوت بعد إضافة مفتاحه إلى Railway وتفعيل الخدمة.

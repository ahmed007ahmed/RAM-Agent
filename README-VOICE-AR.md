# RAM voice session repair v1

هذا التحديث يحافظ على تكامل n8n الموجود ويعالج ثلاث نقاط: التقاط الصوت المستمر حتى الصمت ثم تحويله عبر Whisper، رد فوري على التحية وحدها، وإصلاح انتظار Cloudflare الطويل مع إظهار سبب رفضه.

## الملفات
استبدل المسارات التالية في مستودع GitHub:
- `app/src/main/java/com/ram/agent/VoiceConversationService.java`
- `app/src/main/java/com/ram/agent/MainActivity.java`
- `app/src/main/assets/app.js`
- `server/server.js`

لا تستبدل ملفات `AndroidManifest.xml` أو `package.json`؛ إذن الميكروفون ومكتبات الخادم الحالية كافيان. يتضمن ملف الخادم تكامل n8n الحالي، ويوقف طلب المحادثة بعد 12 ثانية بدل 45 ثانية. كما يرسل rejectIfBusy لتفادي طابور الانتظار، ويعيد توضيح أخطاء Cloudflare مثل الصلاحية أو الفوترة أو عدم وجود النموذج/البوابة. التحية وحدها تحصل على رد فوري من الخادم؛ أما الرسائل التي تتضمن سؤالًا أو طلبًا فتذهب إلى النموذج.

## خطوات النشر
1. أنشئ رمز Cloudflare جديدًا بصلاحية Workers AI Read وWorkers AI Edit؛ لا تعدّل المتغير قبل نسخ الرمز الجديد.
2. في Railway > خدمة RAM-Agent > Variables حدّث CLOUDFLARE_API_TOKEN بالرمز الجديد، ثم اضغط Deploy وانتظر اكتمال النشر.
3. ارفع ملفات الحزمة الأربعة إلى المسارات نفسها في مستودع GitHub (استبدال الملفات، وليس رفع ZIP داخل المستودع). انتظر نجاح GitHub Actions ثم ثبّت APK الجديد.
4. افتح المحادثة واختبر «السلام عليكم» ثم سؤالًا عاديًا. اختبر الصوت بزر بدء المحادثة؛ بعد النشر سيظهر خطأ محدد إذا كانت صلاحية الحساب أو خطة الدفع غير مكتملة.

## ما الذي يتطلبه Whisper؟
يستخدم المسار الجديد متغيري Railway الموجودين: `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN`. الرمز الذي أنشأته في الصور يفتقد صلاحية Workers AI Edit؛ كان ملخصه Workers AI Read فقط. أنشئ رمزًا جديدًا يتضمن Workers AI Read وWorkers AI Edit (وأبقِ صلاحية AI Gateway كما هي)، ثم استبدل قيمة CLOUDFLARE_API_TOKEN في Railway بالرمز الجديد واضغط Deploy. لا ترسل الرمز في المحادثة. نموذج glm-5.3-flash يتطلب خطة Workers مدفوعة أو رصيد AI Gateway مسبق الدفع؛ إذا لم تتوفر، غيّر CLOUDFLARE_AI_MODEL إلى نموذج متاح في خطتك. لا تضع أي قيمة نموذجية غير مؤكدة؛ استخدم صفحة النماذج في Cloudflare.

يستمع رام على الهاتف، وينهي المقطع بعد نحو 1.3 ثانية من الصمت، ثم يرسله كاملًا (حتى 90 ثانية) للتفريغ النصي، وبعد رد رام يبدأ الاستماع من جديد. لا تستخدم هذه المرحلة خدمة البوق القديمة. هذا تبادل صوتي متتابع، وليس بثًا صوتيًا كاملًا أثناء الكلام؛ Whisper في Workers AI يعمل على المقاطع الصوتية. للصوت الطبيعي اختَر ElevenLabs في إعدادات الصوت بعد إضافة مفتاحه إلى Railway وتفعيل الخدمة.

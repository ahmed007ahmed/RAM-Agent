# تحديث رام: اكتشاف أعمال مجانية متعددة المجالات

## ما الذي يتغير؟

- يضيف تصنيفًا لفرص الترجمة والكتابة والتصميم والإعلانات والويب والهندسة/CAD/3D واللوجستيات والشحن والتوريد والبحث والبيانات والمساعدة الافتراضية وخدمة العملاء والمبيعات والتسويق والفيديو والأتمتة والتعليم.
- يوضح طريقة التعامل المناسبة مع الفرصة: مسودة تحتاج مراجعة، مخرج هندسي يحتاج مراجعة مختص، أو بحث وتنسيق لوجستي فقط.
- لا يضيف رسومًا أو مفاتيح مدفوعة، ولا يرسل عروضًا أو رسائل ولا يحجز شحنات.

## الملفات

استبدل الملفات الثلاثة في مجلد `server` بالمستودع:

- `free-opportunity-connectors.js`
- `free-opportunity-connectors.test.js`
- `FREE-OPPORTUNITY-APIS.md`

ثم ارفع التغييرات إلى GitHub وانتظر اكتمال إعادة النشر في Railway. لا يحتاج هذا التحديث إلى تغيير متغيرات Railway أو إعادة بناء APK.

## الحد الحالي

مصادر البحث الأربعة ما زالت خلاصات قراءة عامة للوظائف/العقود. التصنيف الأوسع لا يعني أن كل مجال لديه مصدر فرص مستقل أو أن التقديم الآلي صار متاحًا. لا يُقبل أي عمل تتطلب فرصته دفعًا مقدمًا، ويجب التحقق من الرسوم وشروط البلد قبل التقديم.

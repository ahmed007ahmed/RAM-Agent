تحديث RAM 1.16 — إصلاح المحادثة ونقاش الأعمال وبيانات الاستلام

طريقة التثبيت:
1) فك ضغط RAM-CHAT-PAYOUT-FIX.zip.
2) انسخ المجلدات والملفات الناتجة إلى جذر مستودع RAM-Agent على GitHub مع السماح بالاستبدال.
3) ارفع التغييرات إلى main وانتظر اكتمال GitHub Actions.
4) ثبّت APK الناتج، ثم افتح الإعدادات مرة واحدة واحفظ اسم المستلم ورقم الهاتف وطريقة الاستلام على الهاتف.

يتضمن التحديث:
- إصلاح محاولة اتصال المحادثة مرة أخرى عند انقطاع الاتصال المؤقت، وتنظيف وسوم Safety الداخلية.
- تحسين أسلوب رد النموذج والتناوب بين نماذج OpenRouter المتاحة.
- نقل مربع الكتابة إلى أعلى سجل المحادثة.
- نقاش محفوظ داخل كل عمل قيد التنفيذ، مع سياق العمل ومسودته.
- حفظ طريقة الاستلام مع الصفقة، وحفظ عنوان USDT محليًا بعد إدخاله في محادثة رام مع الشبكة.
- عرض بيانات المستلم محليًا في إعدادات التطبيق، وعدم تضمين الاسم أو الهاتف داخل مستودع GitHub.

حدود واضحة:
- هذا التحديث لا يسجّل أو يوقّع عقدًا، ولا يرسل عروضًا أو مخرجات تلقائيًا إلى منصة، ولا يحوّل الأموال.
- إعداد ElevenLabs يتطلب تمكين ALLOW_PAID_TTS على Railway؛ تشغيله يستهلك رصيد الحساب. صوت الهاتف الافتراضي مجاني لكنه قد يبدو آليًا.
- بيانات الاستلام تحفظ على الهاتف بعد إدخالها وحفظ الإعدادات، ولم تُكتب داخل المصدر العام.
- لا يتضمن الأرشيف APK؛ يصنعه GitHub Actions بعد رفع الملفات.

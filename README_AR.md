# تحديث المحادثة الصوتية في RAM

هذه الحزمة تصلح تراجع الصوت في تطبيق Android وتُبقي آخر الرسائل في أعلى المحادثة. ملفات Android مأخوذة من فرع `main` الحالي في مستودع RAM-Agent، ثم عُدلت لتضيف وضع المحادثة الصوتية.

## ما يتغير

- زر واحد لبدء المحادثة الصوتية وإيقافها.
- بعد سماع كلامك، يرسل رام النص إلى المحادثة، ينطق الرد، ثم يعود للاستماع ما دام الوضع مفعّلًا.
- تبقى الخدمة الصوتية فعالة عند الانتقال إلى تطبيق آخر، مع إشعار مستمر وزر إيقاف في الإشعار.
- لا تفتح نافذة التسجيل القديمة. يبقى حقل الكتابة متاحًا في كل وقت.
- يظهر أحدث كلام ورد في أول المحادثة، بما في ذلك مناقشات العمل.
- لا تتغير ملفات الخادم أو إعدادات Railway أو متغيرات الأسرار.

## طريقة النسخ إلى GitHub من الهاتف

1. نزّل ملف ZIP وفك ضغطه.
2. افتح مستودع `ahmed007ahmed/RAM-Agent` على GitHub، فرع `main`.
3. انسخ الملفات إلى المسارات نفسها داخل المستودع، واستبدل الملفات الموجودة عند تطابق المسار. أضف ملف `VoiceConversationService.java` الجديد.
4. ارفع التعديلات. سيبني سير GitHub Actions ملف APK وفق إعداد المستودع الحالي.
5. نزّل APK الناتج وثبّته على الهاتف. هذا تحديث لتطبيق Android، لذلك نشر Railway وحده لا يحدّث واجهة الهاتف.
6. افتح RAM، ادخل المحادثة، واضغط «بدء المحادثة الصوتية» واسمح للميكروفون. لإيقافه اضغط الزر نفسه أو «إيقاف» في إشعار Android.

## الملفات

- `app/src/main/assets/app.js`
- `app/src/main/assets/index.html`
- `app/src/main/AndroidManifest.xml`
- `app/src/main/java/com/ram/agent/MainActivity.java`
- `app/src/main/java/com/ram/agent/VoiceConversationService.java` (جديد)

اترك `core.js` وملفات الخادم وGradle وGitHub Actions وسائر ملفات المشروع كما هي.

## سلوك الصوت وحدوده

هذا وضع محادثة يبدأ بإجراء صريح منك، ويستمع لجملة، يرسلها، وينطق الرد، ثم يعيد الاستماع. يحتاج إذن الميكروفون وإشعار الخدمة الأمامية. خدمة Android للتعرف على الكلام ليست مصممة للاستماع المتواصل بلا توقف، وقد يستهلك تكرار الاستماع البطارية والبيانات؛ لذلك لا يتضمن التحديث كلمة تنبيه دائمة مثل «Hey Google». التعرف واللغة العربية يعتمدان على خدمة التعرف وحزم اللغة المثبتة على الهاتف، وقد يحتاجان اتصالًا بالشبكة.

هذا التحديث لا يضيف n8n بعد؛ يحافظ على الخادم والتكاملات الحالية دون تغيير. تضاف وصلة n8n في تحديث مستقل بعد التأكد من نجاح APK والصوت.

## الفحص

شُغّل فحص صياغة JavaScript وقراءة XML للحزمة. لا يتوفر Android SDK/Gradle كامل في مساحة إعداد الحزمة، لذلك يجب التأكد من نجاح GitHub Actions قبل تثبيت APK. يُختبر على الهاتف: السماح بالميكروفون، سؤال صوتي ورد منطوق، عودة الاستماع بعد الرد، الانتقال لتطبيق آخر ثم تجربة جملة، والإيقاف من الزر ومن الإشعار.

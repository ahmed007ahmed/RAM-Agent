# تحديث RAM: المحادثة والرد الاحتياطي

هذه حزمة تعديل محدودة لنسخة `ahmed007ahmed/RAM-Agent` الحالية. الملفات الثلاثة فقط تتغير:

- `server/server.js`: عند تعطل OpenRouter بسبب ازدحام أو خلل مؤقت، يحاول RAM استخدام مفتاح Gemini الموجود في إعدادات الخادم. اسم النموذج الافتراضي `gemini-3.8-flash` ويمكن تغييره عبر `GEMINI_MODEL`. عند فشل المزودين معًا تظهر رسالة أوضح.
- `app/src/main/assets/app.js` و`index.html`: يظهر سجل المحادثة قبل خانة الكتابة، وتبقى خانة الكتابة مثبتة أسفل الشاشة.

لا تستبدل `MainActivity.java` أو `AIService.java` أو ملفات البيانات. لا يوجد مفتاح أو رمز سري داخل الحزمة.

## قبل تثبيت التعديل

تحقق في Railway من وجود قيمة صالحة لمتغير `GEMINI_API_KEY`، ولا ترسل قيمته في المحادثة أو GitHub. إذا لم يكن المفتاح صالحًا، سيظل OpenRouter يعمل كالمعتاد وستظهر رسالة الازدحام عند رفضه.

## حالة Gmail

الحزمة لا تدّعي إصلاح ربط Gmail. الخادم المنشور لا يحتوي مسارات OAuth التي يطلبها التطبيق، وتُظهر سجلات Railway أن `/gmail/oauth/start` رجع 404. كما لم أجد متغيرات `GOOGLE_CLIENT_ID` أو `GOOGLE_CLIENT_SECRET` في خدمة Railway. يلزم تنفيذ مسارات OAuth وتخزين رمز التجديد في مخزن دائم ومشفّر، ثم إضافة اعتماد Google وتفويض الحساب. لا تضع كلمات مرور Google أو رموز OAuth في التطبيق أو المحادثة.

كل خدمة إضافية تحتاج OAuth أو API خاصًا بها وموافقة صاحب الحساب؛ لا يوجد تسجيل آمن واحد بالبريد ينشئ حسابات تلقائيًا في كل المواقع.
